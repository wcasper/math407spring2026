Solve each of the following problems.
If the problem asks for a proof, be sure to carefully justify your work, including any theorems from class.

Note: you may NOT use a theorem or result from class to prove something when it makes the problem entirely trivial.  If you are unsure whether a particular theorem or result is allowed, just ask!

## Problem 1 (True or False)
For each of the following, write TRUE if the statement is true and FALSE if the statement is false.  NO explanation is needed.

Assume $$F$$ is a field.

* (a) The ring $$\mathbb Z$$ is a PID
* (b) The ideal of $$F[x]$$ generated by an irreducible polynomial is maximal
* (c) In a GCD domain, any two nonzero elements have a unique greatest common divisor
* (d) If $$f(x)\in\mathbb Q[x]$$ has a repeated root then it must be reducible
* (e) Any polynomial $$f(x)\in F[x]$$ has a splitting field 

## Problem 2

For each of the following fields, either prove that the field is a splitting field over $$\mathbb Q$$, or prove that it is not.

* (a) $$\mathbb Q(\sqrt[3]{5})$$
* (b) $$\mathbb Q(\sqrt{i})$$
* (c) $$\mathbb Q(\sqrt{2},\sqrt{3})$$
* (d) $$\mathbb Q(\pi)$$

## Problem 3

Give an example of each of the following

* (a) A field which is not separable
* (b) A ring which is not a UFD
* (c) An algebraic field extension of $$\mathbb{Q}$$ with infinite degree
* (d) A field extension whose Galois group is isomorphic to $$\mathbb Z_5$$


## Problem 4

* (a) Write down the definition of a Euclidean domain
* (b) Write down the definition of a PID
* (b) Write down the definition of a GCD domain
* (c) Prove that any Euclidean domain is a PID
* (d) Prove that any PID is a GCD domain

## Problem 5

Let $$m$$ and $$n$$ be positive integers.  

* (a) Write down the descent criterion for groups.
* (b) Write down the descent criterion for rings.
* (c) Determine, with proof, for which values of $$m$$ and $$n$$ there is a nonzero group homomorphism from $$\mathbb Z_m$$ to $$\mathbb Z_n$$
* (d) Determine, with proof, for which values of $$m$$ and $$n$$ there is a nonzero ring homomorphism from $$\mathbb Z_m$$ to $$\mathbb Z_n$$

## Problem 6

Let $$F\subseteq K$$ be a normal field extension of degree $$n$$.

* (a) Write down the definition of a normal field extension.
* (b) Write down the definition of a splitting field.
* (c) Prove that $$K$$ must be the splitting field of some polynomial in $$F[x]$$.

## Problem 7

Let $$m$$ and $$n$$ be positive integers.

* (a) State the First Isomorphism Theorem for groups.
* (b) Determine the image and the kernel of the group homomorphsm

$$f: \mathbb Z\rightarrow Z_{m}\times\mathbb Z_n,\quad f(x) = (x\mod m,x\mod n).$$
* (c) If $$\gcd(m,n)=1$$, use part (b) to prove that $$\mathbb Z_{mn}$$ is isomorphic to $$\mathbb Z_m\times\mathbb Z_n$$.
