Solve each of the following problems.
If the problem asks for a proof, be sure to carefully justify your work, including any theorems from class.

Note: you may NOT use a theorem or result from class to prove something when it makes the problem entirely trivial.  If you are unsure whether a particular theorem or result is allowed, just ask!

## Problem 1 (True or False)
For each of the following, write TRUE if the statement is true and FALSE if the statement is false.  NO explanation is needed.

a) if $$G$$ is not Abelian and $$H\leq G$$, then $$H$$ is not Abelian

b) If $$H$$ and $$K$$ are subgroups of a group $$G$$, then the intersection $$H\cap K$$ is also a subgroup of $$G$$

c) If $$G$$ is a group of order $$4$$, then $$G$$ must be a cyclic group

d) $$-\omega_3$$ is a primitive sixth root of unity.

e) The set $$\{0,2,4\}$$ is a subgroup of $$Z_5$$

## Problem 2

a) Write down the definition of a symmetric polynomial.
b) State the Fundamental Theorem of Symmetric polynomials.
c) Suppose that $$z_1,\dots, z_4$$ are the roots of the polynomial

$$1 + 2x + 5x^2 + 7x^3 + x^4 = 0.$$

Determine the value of 

$$z_1^3 + z_2^3 + z_3^3 + z_4^3.$$

## Problem 3

a) Write down the definition of a cyclic subgroup and a cyclic group.

b) Prove that if $$G$$ is a cyclic group, then every subgroup of $$G$$ is also cyclic.

c) Determine all the subgroups of $$\mathbb Z_{12}$$

## Problem 4

Let $$G$$ be a group.

a) Write down the definition of a group.

b) Write down the definition of a group being Abelian.

c) Prove that if $$G$$ is a group where $$g^2=e$$ for all $$g\in G$$, then $$G$$ is Abelian.

## Problem 5

a) Write down the definition of the set $$U_n$$ of $$n$$'th roots of unity.

b) Prove that for $$\omega_n = e^{2\pi i/n}$$

$$U_n = \{1,\omega_n,\omega_n^2,\dots,\omega_n^{n-1}\}.$$

c) Let $$n>0$$ be odd.  Determine the value of

$$\frac{1}{1 + 1} + \frac{1}{1 + \omega_n} + \frac{1}{1+\omega_n^2} + \dots + \frac{1}{1+\omega_n^{n-1}}.$$

[Hint: if $$z$$ is a root of $$p(z)$$, then $$\frac{1}{1+z}$$ is a root of $$z^n p(1/z-1)$$]

## Problem 6

Consider the set

$$G=\{(a,b): \text{$a,b$ integers},\ 0\leq a < 7,\ 0\leq b < 3\}$$

with the associative binary operation

$$(a,b)\ast (c,d)  = (a +_7 (2^bc), b +_3 d).$$

For example
$$(3,2)*(5,1) = (3 +_7 (2^25),2+_31) = (3 +_7 20, 0) = (2,0).$$

a) Show that $$G$$ has an identity element

b) Show each element of $$G$$ has an inverse

c) Show that $$G$$ is not Abelian

d) Find the order of the element $$(1,1)$$ in $$G$$.  Show your work.

## Problem 7

a) Write down the definition of a permutation of $$[n] = \{1,2,\dots,n\}$$ and the definition of the symmetric group.
b) Rewrite the following permutation in $$S_9$$ in cycle notation.

$$\binom{1\ 2\ 3\ 4\ 5\ 6\ 7\ 8\ 9}{8\ 6\ 7\ 5\ 3\ 1\ 9\ 2\ 4}$$

c) Rewrite the following permutation in standard notation in $$S_9$$

$$(1\ 3\ 5)(2\ 4)(7\ 8)$$

d) Calculate the following product and express the result in cycle notation

$$(1\ 3\ 9)(4\ 6\ 5\ 9)(2\ 7\ 1\ 9)$$

e) Explain why the product of three $$4$$-cycles in $$S_n$$ can never be equal to the product of four $$3$$-cycles.
