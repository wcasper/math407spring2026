## Problem 2

a) Write down the definition of a symmetric polynomial.
b) State the Fundamental Theorem of Symmetric polynomials.
c) Suppose that $$z_1,\dots, z_4$$ are the roots of the polynomial

$$1 + 2x + 5x^2 + 7x^3 + x^4 = 0.$$

Determine the value of 

$$z_1^3 + z_2^3 + z_3^3 + z_4^3.$$


**Solution:**

a) A polynomial $$p(z_1,\dots, z_n)$$ is symmetric if

$$p(z_1,\dots, z_n) = p(z_{\sigma(1)},\dots, z_{\sigma(n)})\ \forall \sigma\in S_n.$$

b) Any symmetric polynomial can be expressed as a sum of products of elementary symmetric polynomials.

c) Using the elementary symmetric polynomials,

$$z_1^3+z_2^3+z_3^3+z_4^3 = e_1^3-3e_1e_2+3e_3.$$

Therefore by Vieta's Theorem:

$$z_1^3+z_2^3+z_3^3+z_4^3 = (-7)^3-3(-7)(5)+3(-2).$$

## Problem 3

a) Write down the definition of a cyclic subgroup and a cyclic group.

b) Prove that if $$G$$ is a cyclic group, then every subgroup of $$G$$ is also cyclic.

c) Determine all the subgroups of $$\mathbb Z_{12}$$

**Solution:**

a) A cyclic subgroup is a subgroup generated by a single element, ie. of the form $$\langle a\rangle$$ for some element $$a$$ of the group.  A group is cyclic if it is equal to one of its cyclic subgroups.

b) Let $$G = \langle g\rangle$$ and suppose that $$H\leq G$$.  Define

$$r = \min\{k > 0: g^k\in H\}.$$

To prove $$H$$ is cyclic, we will prove $$H = \langle g^r\rangle$$.

Since $$H$$ is a subgroup of $$G$$ containing $$g^r$$, the definition of the subgroup generated by $$g^r$$ implies $$\langle g^r\rangle \subseteq H$$.

Thus to complete our proof, it suffices to show $$H\subseteq \langle g^r\rangle$$.
If $$h\in H$$, then $$h=g^k$$ for some $$k$$.  Moreover, by the Euclidean algorithm there exist integers $$m,n$$ with

$$mk + nr = \gcd(k,r).$$

Since $$g^r,h\in H$$, it follows that

$$(g^r)^nh^m = g^{mk+nr} = g^{\gcd(k,r)}\in H.$$

The minimality of $$r$$ then implies $$\gcd(k,r)\geq r$$.  Therefore $$\gcd(k,r) = r$$, so that $$k=\ell r$$ for some integer $$\ell$$.  Therefore

$$h=g^{\ell r} = (g^r)^\ell\in \langle g^r\rangle.$$

This proves $$H\subseteq \langle g^r\rangle.$$  It follows $$H=\langle g^r\rangle$$ and therefore $$H$$ is a cyclic subgroup of $$G$$

c)  Since $$\mathbb Z_{12}$$ is cyclic, we know all the subgroups will be cyclic.  Therefore, we need only determine the subgroups generated by single elements.
We have 

$$\begin{align}
\langle 0\rangle &= \{0\}\\
\langle 1\rangle = \langle 5\rangle = \langle 7\rangle = \langle 11\rangle &= \mathbb Z_{12}\\
\langle 2\rangle = \langle 10\rangle &= \{0,2,4,6,8,10\}\\
\langle 3\rangle = \langle 9\rangle &= \{0,3,6,9\}\\
\langle 4\rangle = \langle 8\rangle &= \{0,4,8\}\\
\langle 6\rangle &= \{0,6\}
\end{align}$$

In particular there are only 6 different subgroups.

## Problem 4

Let $$G$$ be a group.

a) Write down the definition of a group.

b) Write down the definition of a group being Abelian.

c) Prove that if $$G$$ is a group where $$g^2=e$$ for all $$g\in G$$, then $$G$$ is Abelian.

**Solution:**

a) A group is a set $$G$$ with a binary operation $$*$$ satisfying the properties:

  - i) $$a*b\in G$$ for all $$a,b\in G$$
  - ii) $$a*(b*c) = (a*b)*c$$ for all $$a,b,c\in G$$
  - iii) there is an element $$e$$ with $$e*a=a*e=e$$ for all $$a\in G$$
  - iv) for each $$a\in G$$ there exists $$b\in G$$ with $$a*b=b*a=e$$

b) A group is Abelian if $$a*b=b*a$$ for all $$a,b\in G$$

c) Let $$a,b\in G$$.  Then

$$e=(a*b)*(a*b) = a*b*a*b$$

Multiplying both sides on the left by $$a$$, we get

$$a = a*e = a*a*b*a*b = e*b*a*b = b*a*b.$$

Multiplying both sides on the left by $$b$$, we then get

$$b*a = b*b*a*b = e*a*b = a*b.$$

Therefore $$b*a=a*b$$ for all $$a,b\in G$$.

## Problem 5

a) Write down the definition of the set $$U_n$$ of $$n$$'th roots of unity.

b) Prove that for $$\omega_n = e^{2\pi i/n}$$

$$U_n = \{1,\omega_n,\omega_n^2,\dots,\omega_n^{n-1}\}.$$

c) Let $$n>0$$ be odd.  Determine the value of

$$\frac{1}{1 + 1} + \frac{1}{1 + \omega_n} + \frac{1}{1+\omega_n^2} + \dots + \frac{1}{1+\omega_n^{n-1}}.$$

[Hint: if $$z$$ is a root of $$p(z)$$, then $$\frac{1}{1+z}$$ is a root of $$z^n p(1/z-1)$$]

**Solution:**

a) $$U_n = \{z\in\mathbb{C}: z^n=1\}$$

b) Suppose that $$z^n=1$$.  Write $$z$$ in polar form $$z=re^{i\theta}$$ for $$r\geq 0$$ and $$0\leq \theta < 2\pi$$.  Then we get $$r^ne^{in\theta} = 1$$.  
Then using Euler's identity

$$r^n\cos(n\theta) + ir^n\sin(n\theta) = 1.$$

Since $$r>0$$, it follows that $$r=1$$, $$\cos(n\theta) = 1$$ and $$\sin(n\theta) = 0$$. Therefore $$n\theta = 2\pi k$$ for some integers $$k$$ and $$\theta = 2\pi k/n$$.  Since $$0\leq \theta < 2\pi$$, this shows

$$z = e^{2\pi i k/n} = \omega_n^k,\quad 0\leq k < n.$$

This proves (b).

c) This is a fun problem!  For each $$k$$, $$\frac{1}{1+\omega_n^k}$$ is a root of the polynomial

$$p(z)  = z^n((1/z-1)^n-1) = (1-z)^n-z^n.$$

Then by applyingthe Binomial Theorem, we get

$$p(z) = -2z^n + \binom{n}{1}z^{n-1} - \binom{n}{2}z^{n-2} + \dots + 1$$

By Vieta's Theorem, the quantity we are looking for is then $$n/2$$.

## Problem 6

Consider the set

$$G=\{(a,b): \text{$a,b$ integers},\ 0\leq a < 7,\ 0\leq b < 3\}$$

with the associative binary operation

$$(a,b)\ast (c,d)  = (a +_7 (2^bc), b +_3 d).$$

For example
$$(3,2)*(5,1) = (3 +_7 (2^25),2+_31) = (3 +_7 20, 0) = (2,0).$$

a) Show that $$G$$ has an identity element

b) Show each element of $$G$$ has an inverse

c) Show that $$G$$ is not Abelian

d) Find the order of the element $$(1,1)$$ in $$G$$.  Show your work.

**Solution:**

a) $$(a,b)\ast (0,0) = (a,b)$$ and $$(0,0)\ast (a,b) = (a,b)$$ so $$(0,0)$$ is an identity for $$G$$

b) 

$$(a,b)\ast (4^b6a,2b) = (a +_7 (2^b4^b6a), b+_32b) = (a +_7 (8^b6a),3b) = (a +_7(6a),0) = (7a,0) = (0,0).$$

Likewise 

$$(4^b6a,2b)\ast (a,b) = (4^b6a +_7 2^{2b}a, 2b+_3b) = (2^{2b}6a +_7 2^{2b}a, 3b) = (2^{2b}7a,0) = (0,0).$$

Therefore the inverse of $$(a,b)$$ is $$(4^b6a,2b)$$.

c) $$(1,0)\ast (1,1) = (1+_72^01,0+_31) = (2,1)$$ and $$(1,1)\ast(1,0) = (1+_72^11,1+_30) = (3,1)$$.  Therefore the group is non-Abelian

d) 

$$(1,1)\ast (a,b) = (1+_72^1a,1+_3a) = (2a+_71,a+_31)$$

Therefore

$$\begin{align*}
(1,1)^2 = (1,1)\ast (1,1) &= (3,2)\\
(1,1)^3 = (1,1)\ast (3,2) &= (0,0).
\end{align*}$$


Thus $$(1,1)$$ has order $$3$$.

## Problem 7

a) Write down the definition of a permutation of $$[n] = \{1,2,\dots,n\}$$ and the definition of the symmetric group.
b) Rewrite the following permutation in $$S_9$$ in cycle notation.

$$\binom{1\ 2\ 3\ 4\ 5\ 6\ 7\ 8\ 9}{8\ 6\ 7\ 5\ 3\ 1\ 9\ 2\ 4}$$

c) Rewrite the following permutation in standard notation in $$S_9$$

$$(1\ 3\ 5)(2\ 4)(7\ 8)$$

d) Calculate the following product and express the result in cycle notation

$$(1\ 3\ 9)(4\ 6\ 5\ 9)(2\ 7\ 1\ 9)$$

e) Explain why the product of three $$4$$-cycles in $$S_n$$ can never be equal to the product of four $$3$$-cycles.

**Solution:**

a) A permutation is a bijection from $$[n]$$ to $$[n]$$

b) $$(1\ 8\ 2\ 6)(3\ 7\ 9\ 4\ 5)$$

c)

$$\binom{1\ 2\ 3\ 4\ 5\ 6\ 7\ 8\ 9}{3\ 4\ 5\ 2\ 1\ 6\ 8\ 7\ 9}$$

d) $$(1\ 4\ 6\ 5)(2\ 7\ 3\ 9)$$

e) Parity!  A $$3$$-cycle is even, si the product of any number of $$3$$-cycles will be even.  However, a $$4$$-cycle is odd, so the product of three $$4$$-cycles will also be odd.
